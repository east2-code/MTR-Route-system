# MTR-Route-system
A Hong Kong MTR route planning system was written in Python. The Dijkstra algorithm and heap sort method were used to find the optimal path. Users can find the optimal route to their destination. This map is updated with the Hong Kong MTR data in 2025.

This Python program allows the user to enter the start station and destination station, and then get the optimal route and time and transfer message, using dijkstra's algorithm and heap sorting.
